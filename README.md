## Project Overview

This project focuses on automating the authentication process for a user login system using Java and TestNG. 
It demonstrates the use of DataProviders to handle multiple test scenarios, including valid credentials, invalid attempts,
and edge cases like null or empty values.


## Key Features

Data-Driven Testing: Utilizing @DataProvider to separate test data from test logic.

Happy & Sad Path Coverage: Specialized test methods for successful and failed authentication.

Edge Case Handling: Robust testing against empty strings and null inputs.

TestNG Suite Configuration: Organized testing via testng.xml for structured

## Technologies Used
